# Unified Dubbing Colab coordinator

## What was added

`notebooks/LA_STUDIO_UNIFIED_DUBBING_GPU.ipynb` is the real implementation behind the optional **Unified Dubbing Colab** setup. It is generated by `scripts/generate_unified_dubbing_colab_notebook.py` and embeds `notebooks/workers/LA_STUDIO_UNIFIED_DUBBING_COORDINATOR.py`.

It performs the following work before it prints a URL or reports readiness:

1. Clones LA Studio at one pinned Git commit, not a moving branch.
2. Reads `UNIFIED_WORKERS`, whose entries are exact capability/model pairs.
3. Locates the corresponding generated exact notebook for every entry.
4. Performs that notebook's package/artifact preparation and starts the actual worker on a private loopback port.
5. Waits for the worker's authenticated `/health` response, including `ready: true`, the selected model identity, and `device: cuda`.
6. Starts one Cloudflare quick tunnel only after every selected worker passes this check.
7. Proxies the normal worker route through `/v1/unified/<capability>/<model>/<worker-route>` using the same bearer token.

The notebook prints exactly one `LA_STUDIO_UNIFIED_DUBBING_URL` and one `LA_STUDIO_UNIFIED_DUBBING_TOKEN`. Paste them once into the optional Unified Dubbing setup. Existing per-model Colab routes remain independent and unchanged.

## Choosing workers

Edit `UNIFIED_WORKERS` in the notebook before its final cell. Each Dubbing model selected in the app must have a matching `capability` and `model` entry. The shipped list covers the default direct stages: Spleeter isolation, Whisper STT, PP-OCRv5, M2M100 translation, Kokoro TTS, and MMS forced alignment.

If a selected worker cannot install, load CUDA, identify itself as the requested model, or pass `/health`, the coordinator fails and shows that worker's own log. It does not silently use CPU, API Gateway, another model, or a simulated `ready` response.

## Validation completed locally

- `python -m py_compile notebooks/workers/LA_STUDIO_UNIFIED_DUBBING_COORDINATOR.py scripts/generate_unified_dubbing_colab_notebook.py scripts/verify_unified_dubbing_colab_notebook.py`
- `python scripts/generate_unified_dubbing_colab_notebook.py`
- `python scripts/verify_unified_dubbing_colab_notebook.py`
- `ctest --test-dir out/build/windows-msvc-tests -R DubbingProject --output-on-failure`

The static contract verifier checks that the tracked notebook matches its generator, contains the authenticated unified route and real-health barrier, and can extract/compile the six default exact worker sources. A live Colab GPU run still depends on the specific Colab runtime and each upstream package/model download; it has not been represented as locally completed.
