# vietnorm upstream provenance

The initial implementation is a C++17/Qt port of
[`vietnormalizer` 0.2.3](https://github.com/nghimestudio/vietnormalizer) at
commit `dd38778731d6ca4e9e670a19abb2df1c901a1852`. Its `LICENSE` identifies
the MIT license and the copyright holder as Vietnamese Normalizer Contributors.

The rule pipeline is also derived from the JavaScript implementation in
[`nghitts/src/utils/`](https://github.com/nghimestudio/nghitts). The upstream
`nghitts` repository publishes its source under Apache-2.0.

`LICENSE` contains Apache-2.0 and `NOTICE` preserves the upstream attribution
and the full MIT text. Keep both files with this module and update this record
before importing any new upstream code or data.
